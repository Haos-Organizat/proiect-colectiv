01, Color tokens

Warm ink, paper white, one signal red.

shadcn/ui token names. The swatches below read their values straight from the CSS variables, so this page runs on the same tokens it documents. In light mode the red shifts darker (#D0261A) so it passes as text and as a button fill with white type. The bright #FF4130 stays as --brand for big poster blocks and the logo dot.

Errors are not the brand red

The brand owns red-orange (hue around 5 degrees). Destructive moves to raspberry in light mode (#B4135A, hue around 335) and pink in dark mode (#FF6B9E). On top of the hue shift, an error is never color alone: it always carries the icon, a written message, and a 2px border, so it reads correctly for color-blind users too.

06, Motion

Moves once, then sits still.

Motion marks a moment, it never decorates. Every animation runs once, nothing loops, and all of it is wrapped in prefers-reduced-motion: no-preference. With reduced motion on, content just appears.

Where things move

  1. Ticket reveal. When a ticket card enters the screen the first time: fade plus 24px rise, 480ms, cubic-bezier(0.2, 0.8, 0.2, 1). The QR area follows 200ms later with 320ms. Also used once after a successful purchase.
  2. Log in / register switch. The new panel fades in with an 8px rise, 220ms, same easing. No slide between tabs.
  3. Button press. Scale to 0.98 for 80ms on press. Hover is a 150ms ease-out color change only.
  4. Not animated: page loads, scrolling, cards on hover, theme switch, toasts, the logo, anything in a loop.

07, Do and don't

Keep the signal clean.

Do

  • Use red for one thing per view: the main action, or one poster block.
  • Set headlines big and tight in Bricolage 750 to 800, then let the body breathe.
  • Put dates, prices and ticket codes in DM Mono.
  • Use the darker primary (#D0261A) for red text and buttons in light mode.
  • Pair every error with the warning icon and a written message.
  • Keep icons plain, beside their label, in the text color or primary.

Don't

  • Don't set body text in #FF4130 on paper, it only reaches 3.3:1.
  • Don't use the brand red for errors or delete actions.
  • Don't add gradients, glows, pulsing dots or anything that loops.
  • Don't put icons in circles, tiles or outlined boxes.
  • Don't animate scrolling, hover lifts or page loads.
  • Don't drop inputs below 16px, iOS will zoom the page.
