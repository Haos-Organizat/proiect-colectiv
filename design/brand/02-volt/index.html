Ticket anatomy

  • Top half: who, when, where. Bottom half (the stub): the QR and the code, mono, letter-spaced so door staff can read it aloud.
  • The QR always sits on a white plate with near-black modules, in both themes, so scanners never struggle in dark mode.
  • Status uses a word plus a check icon, never a pulsing dot.
  • The reveal plays once when the ticket first scrolls into view. With reduced motion it simply appears.
05 / Motion

Move only on purpose

Four places animate, each runs once per user action, nothing loops. All of it lives inside @media (prefers-reduced-motion: no-preference); with reduced motion the end state is shown instantly. The live example is the ticket reveal in screen 4 (use Replay).

06 / Favicon

The U mark

A blocky volt U for UniConnect, set on an ink ticket stub whose side notches line up with the U, so the two arms read as two people joined at the base. Ink body keeps a clear edge on light tabs, the volt U carries it on dark tabs, so no color-scheme switch is needed inside the SVG.

07 / Rules

Do / Don't

Do

  • Use volt lime as a fill: primary buttons, the poster block, a NEW badge. Always with ink text on it.
  • Use the olive primary-text (#4A6300) for accent text and links in light mode.
  • Set headlines big, condensed and uppercase. Let one headline own the screen.
  • Put every date, price and ticket code in JetBrains Mono.
  • Use the tear line and notches on ticket-like things: event cards, the buy box, tickets.
  • Keep corners at 4, 6 or 8px.
  • Keep one volt element per view where possible, so it stays loud.

Don't

  • Don't set volt lime text on light backgrounds (1.08:1).
  • Don't add gradients, glows or pill-shaped buttons.
  • Don't animate in loops: no pulsing dots, no blinking "live", no breathing cards.
  • Don't put icons in boxes, circles or colored tiles.
  • Don't use the condensed display face below 22px or for paragraphs.
  • Don't render the QR in theme colors: always ink on white.
  • Don't use cream or warm grays. Neutrals stay cool.
